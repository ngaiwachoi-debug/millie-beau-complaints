# 財務模型

[exposure-model.xlsx](exposure-model.xlsx)含情境輸入、情境支出、方案比較及判例來源四張工作表。藍字是可修改的計劃假設；勝敗機率、訴訟機率及保險貢獻未核實時保持待填。

[財務分析](../audit/2026-10-11/06-financial-exposure.md)說明低、中、高及A–D分支的依據和限制，[判例比較](../audit/2026-10-11/04-case-law-comparison.md)分開法院判賠、替代評估、和解及訟費。歷史數值並非2026年本案賠償上下限。

只加入公開判例及明示管理假設，客戶身份、詳細病歷或原始收據留在受控資料。需要修改公式時才重算及檢查；更新時記錄數值來源及對決策的影響，不把未知值代入0。

本機重建及核查支援在`../evidence/private-local/source-work/build_workbook.py`，不屬GitHub內容。原生Excel重算與渲染的既有限制見[核查說明](../audit/2026-10-11/10-source-verification.md)。
