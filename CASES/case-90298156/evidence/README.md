# 證據入口

本案可及來源成員為57個：WhatsApp44、合約2、療程系統8、醫療文件3。來源照片的標籤不證明裝置拍攝原檔、完整聊天或醫療機構病歷。

[保存與存取登記](storage-and-access.md)列既有Restricted Drive位置、分類封存、數量、大小及來源限制。Drive仍使用舊編號及來源檔名，不因Git案件改名而更改。

| 資料 | 位置／權限 |
| --- | --- |
| 原始上載來源、分類ZIP及閱覽副本 | 既有Restricted Drive，按保存登記及存取檢查使用 |
| 爭點及缺口 | [證據矩陣](../audit/2026-10-11/02-evidence-liability-matrix.md)及[案卷](../CASE.md) |
| 醫學逐項核對及來源雜湊 | 本機`private-local/restricted/`，不追蹤Git |
| 工作副本、OCR及manifest | 本機`private-local/source-work/`，不追蹤Git |

當日設備／DCD、完整原帳與對話、保單及康復仍有缺口，依[下一步](../actions/next-steps.md)調取。沒有實際取得、權限或來源核對時，記錄限制，不把原AI摘要當已確認。
