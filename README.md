> **機密：僅供獲授權的管理層及法律顧問使用。Repository 必須設為 Private。**
>
> 本儲存庫只保存經去識別化的文字摘要、內部處理事項及回覆草稿。不得上載客戶姓名、電話、身份證、出生日期、完整病歷、私密照片、原始 WhatsApp 匯出檔或未遮蓋的收據。

## 用途
- 每宗投訴獨立編號、記錄可核實事實、爭議事項及待調查證據。
- 保留重要處理時間、回覆草稿、批准狀態與跟進工作。
- 將 **已核實事實**、**客戶指稱**、**初步推論** 分開記錄；不得以假設填補證據空白。

## 管理原則
1. 有關傷勢和成因，以可核實醫療紀錄及專業意見為依據，不自行作醫學診斷。
2. 保存原始操作紀錄、儀器設定、購買及服務記錄，不覆寫、不刪改。
3. 未完成事實及責任核實前，不作不受支持的肯定或否定陳述。
4. 客戶要求查閱個人資料，按香港適用的資料查閱程序及法定期限處理；本庫只記錄處理狀態。
5. 所有對外正式回覆由授權負責人確認；涉及傷害和解及免責協議，交香港法律顧問審閱。
6. 任何更改以 commit 保留歷史，清楚標示是否草稿、是否發出及實際發出時間。
